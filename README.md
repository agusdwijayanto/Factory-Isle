# Indotopia — Remake kaya Growtopia

Game 2D web single-player: salinan sistem Growtopia yang bisa dimainkan
solo di browser. Pukul blok, tanam benih, panen pohon, splice, kumpulkan
gems, kunci world dengan lock, trade dengan NPC, dan naik level.

Main di: https://agusdwijayanto.github.io/Indotopia/

## Cara main

- **HP:** tombol sentuh kiri/kanan jalan, LOMPAT, PUKUL. Ketuk dock
  KEPALAN/KUNCI untuk ganti mode Fist/Wrench.
- **Laptop:** A/D atau panah jalan, W/spasi lompat, klik pukul/taruh,
  Q ganti Kepalan/Kunci, I tas, B buku, P profil, G guild, Enter chat,
  scroll zoom.
- **Panel ADMIN** di HUD untuk mengetes fitur tanpa main dari nol.

## Sistem

World bernama 100x60, rumus tumbuh r^3+30r detik, splice benih-di-atas-bibit,
gems tidak bisa ditrade, lock sebagai uang (100 WL = 1 DL = 100 DL = 1 BGL),
trade lewat wrench, vending machine, guild, WOTD, role Farmer/Builder.

Riset, struktur, PRD, dan task ada di folder `docs/`.
