# Aset gambar Indotopia

Semua PNG di folder ini berasal dari paket **Kenney Tiny**, dibuat oleh Kenney
(www.kenney.nl), lisensi **Creative Commons Zero (CC0)** — bebas dipakai,
diubah, dan disebarluaskan, termasuk untuk proyek komersial, tanpa atribusi
wajib. Kredit ini ditulis sebagai penghargaan, bukan kewajiban lisensi.

Sumber (diunduh 2026-11-15 dari kenney.nl):

- Tiny Factory — https://kenney.nl/assets/tiny-factory
- Tiny Town — https://kenney.nl/assets/tiny-town
- Tiny Farm — https://kenney.nl/assets/tiny-farm
- Tiny Dungeon — https://kenney.nl/assets/tiny-dungeon

Hanya file yang DIPAKAI game yang disalin ke sini (37 dari 132 per paket).
Nama file = nama paket + nomor ubin asli, supaya bisa dilacak kembali ke
paket sumbernya. Semua ubin 16x16, dirender skala 2x (32 piksel per petak)
dengan imageSmoothingEnabled=false.

## Yang tetap digambar prosedural (tidak ada sprite yang cocok di paket)

- Air (sungai, oasis, laut): tidak ada ubin air di keempat paket.
- Pohon palm gurun: tidak ada sprite palm di keempat paket.
- Kapal bajak laut: tidak ada sprite kapal di keempat paket.
- Titik warna pembeda bijih di atas tumpukan batu: penanda gameplay, sengaja
  dipertahankan supaya jenis bijih tetap mudah dibedakan.
- Item kecil di atas conveyor, garis batas plot/plaza, label nama, dan
  penanda arah pemain: elemen UI, bukan objek dunia.
